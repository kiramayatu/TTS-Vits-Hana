Voice profiles are saved locally in this browser. They store Speed, Noise scale, Noise scale W, and Sentence max chars. “Reset to Defaults” only changes the controls; it does not delete saved profiles.

Generate Voice uses sentence-sized VITS units internally, starts playing each completed unit immediately, and combines the same units into one final WAV for playback and download.
